# Tic Tac Toe

This project uses HTML, CSS and Javascript to create a Tic Tac Toe game.

## The Odin Project: Lesson Tic Tac Toe

This project is build according to the specification of the [Tic Tac Toe lesson](https://www.theodinproject.com/lessons/node-path-javascript-tic-tac-toe)

## Live website

A multiplayer tic tac toe game. Enter your names and press 'new game'.

Access the [Tic Tac Toe game](https://gohan61.github.io/tic-tac-toe/)
